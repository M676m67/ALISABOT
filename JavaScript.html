Complete JavaScript Guide

js = JavaScript is a powerful, high-level programming language that is mainly used for web development. It allows you to create dynamic and interactive web pages, manipulate the DOM, handle events, perform calculations, work with data, and communicate with servers through APIs. JavaScript can be used on both client-side browser and server-side Node.js.

14. Advanced Topics: Promises & async/await

let promise = new Promise((resolve, reject) => {
    let success = true
    if(success){
        resolve("Task completed")
    }else{
        reject("Task failed")
    }
})
promise.then(result => console.log(result)).catch(error => console.log(error))

async function fetchData(){
    return "Data loaded"
}
fetchData().then(data => console.log(data))
