Complete CSS Guide

CSS = Cascading Style Sheets is used to style and layout web pages. It allows you to control colors, fonts, spacing, positioning, animations, and responsive design. CSS can be added inline, internally inside <;style> tags, or externally via a .css file.

1. Adding CSS

<style>
body {
    font-family: Arial, sans-serif;
    background-color: #f0f0f0;
}
h1 {
    color: #3b82f6;
}
</style>

<link rel="stylesheet" href="style.css">

2. Selectors

/* Element Selector */
p {
    color: red;
}

/* Class Selector */
.demo-class {
    background-color: yellow;
}

/* ID Selector */
#demo-id {
    font-size: 20px;
}

/* Group Selector */
h1, h2, h3 {
    margin-bottom: 10px;
}

/* Descendant Selector */
div p {
    color: green;
}

3. Colors & Backgrounds

body {
    background-color: #e0e0e0;
    color: #333;
}
p {
    color: rgb(255,0,0);
}
div {
    background-image: url("image.jpg");
    background-size: cover;
    background-position: center;
}

4. Fonts & Text

p {
    font-family: "Cairo", sans-serif;
    font-size: 16px;
    font-weight: bold;
    text-align: center;
    text-transform: uppercase;
    letter-spacing: 2px;
    line-height: 1.5;
}

5. Box Model

div {
    width: 200px;
    height: 100px;
    padding: 20px;
    margin: 10px;
    border: 2px solid #3b82f6;
    box-sizing: border-box;
}

6. Display & Positioning

div {
    display: block;
}

span {
    display: inline-block;
}

.container {
    position: relative;
}

.box {
    position: absolute;
    top: 50px;
    left: 100px;
}

.fixed-box {
    position: fixed;
    bottom: 0;
    right: 0;
}

.sticky-box {
    position: sticky;
    top: 0;
}

7. Flexbox

.flex-container {
    display: flex;
    justify-content: space-between;
    align-items: center;
    flex-wrap: wrap;
}

.flex-item {
    flex: 1 1 100px;
    margin: 10px;
    background-color: #3b82f6;
    color: white;
    text-align: center;
    padding: 20px;
}

8. Grid

.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 10px;
}

.grid-item {
    background-color: #3b82f6;
    color: white;
    padding: 20px;
    text-align: center;
}

9. Pseudo-classes & Pseudo-elements

a:hover {
    color: red;
}

a:active {
    color: green;
}

p::before {
    content: "⭐ ";
}

p::after {
    content: " ⭐";
}

10. Transitions & Animations

div {
    width: 100px;
    height: 100px;
    background-color: #3b82f6;
    transition: all 0.5s ease;
}

div:hover {
    background-color: red;
    transform: scale(1.2);
}

@keyframes slide {
    0% { transform: translateX(0); }
    50% { transform: translateX(100px); }
    100% { transform: translateX(0); }
}

.box {
    animation: slide 2s infinite;
}

11. Media Queries (Responsive Design)

@media screen and (max-width: 768px) {
    body {
        background-color: lightblue;
    }
    .container {
        flex-direction: column;
    }
}

12. Shadows & Borders

div {
    border-radius: 10px;
    border: 2px solid #3b82f6;
    box-shadow: 0 4px 8px rgba(0,0,0,0.3);
}

13. Overflow & Scroll

.scroll-box {
    width: 200px;
    height: 100px;
    overflow: auto;
    border: 1px solid #ccc;
}

14. Opacity & Visibility

.hidden {
    visibility: hidden;
}

.transparent {
    opacity: 0.5;
}

15. Z-index & Layering

.behind {
    z-index: 1;
}

.above {
    z-index: 10;
    position: relative;
}
